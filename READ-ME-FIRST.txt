MMcasesBot - JSU + MEMBERSHIP + STOP REPORT FIX
Date: 16/09/2026

IMPORTANT BEHAVIOUR
1. JSU Balance Query
   - Runs the JSU balance lookup.
   - Sends the checked result to the candidate by EMAIL and WhatsApp.
   - Uses JSU-specific no-resend markers, so old generic welcome attempt locks do not block JSU.

2. Mariners Mentor Membership
   - Does NOT send generic welcome communication first.
   - First runs DG Profile + RPSL Sea Service + STCW checker + SID verification/captcha when required.
   - Updates Customer Profile / Course Details / Sea Service sheets and Mariners Mentor customer profile.
   - Only after the data workflow succeeds, sends candidate email + WhatsApp once.

3. Sweety
   - Normal welcome email remains skipped for ordinary Sweety-assigned cases.
   - The admin report does not show the wording "SKIPPED - SWEETY"; that mail cell is shown as '-'.
   - Special JSU Balance and Membership completion workflows are not suppressed by the Sweety welcome-mail rule.

4. Admin report
   - Report recipient: marinersmentor@gmail.com
   - NO admin report is sent during normal running.
   - ONE combined report is sent when the program is stopped.
   - Repeated scheduler passes update/replace the same Case ID row instead of sending repeated reports.

5. Candidate result mail
   - Candidate/result emails go to the candidate's own email address.

Run Main.java in IntelliJ or use RUN-NOW.bat.
